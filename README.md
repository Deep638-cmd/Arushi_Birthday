# 🎂 Happy Birthday Guli — Website Setup Guide

## Folder Structure

```
guli-birthday/
├── index.html          ← Main website (open this in browser)
├── style.css           ← All styles
├── script.js           ← Animations, music, confetti
├── imgs/               ← PUT ALL PHOTOS HERE
│   ├── guli_main.jpg   ← Page 1 — main portrait photo
│   ├── guli1.jpg       ← Gallery photo 1
│   ├── guli2.jpg       ← Gallery photo 2
│   ├── guli3.jpg       ← Gallery photo 3
│   ├── guli4.jpg       ← Gallery photo 4
│   ├── guli5.jpg       ← Gallery photo 5
│   ├── guli6.jpg       ← Gallery photo 6
│   ├── teddy1.png      ← Teddy bear image (optional, emoji fallback)
│   ├── teddy2.png      ← Teddy bear image (optional, emoji fallback)
│   ├── panda1.png      ← Panda image (optional, emoji fallback)
│   └── panda2.png      ← Panda image (optional, emoji fallback)
└── music/              ← PUT THE BIRTHDAY SONG HERE
    └── birthday_song.mp3   ← "Today is Lulu's Birthday" song file
```

---

## ✅ Steps to Personalize

### 1. Add Photos
- Copy Guli's photos into the `imgs/` folder
- Rename them exactly as listed above (e.g. `guli_main.jpg`, `guli1.jpg` … `guli6.jpg`)
- Supported formats: `.jpg`, `.jpeg`, `.png`, `.webp`

### 2. Add the Song
- Copy the MP3 file of **"Today is Lulu's Birthday"** into the `music/` folder
- Rename it to `birthday_song.mp3`

### 3. Add Teddy Bear & Panda Images (Optional)
- Download cute teddy bear / panda images from the internet
- Save them as `teddy1.png`, `teddy2.png`, `panda1.png`, `panda2.png` in the `imgs/` folder
- If you skip this, the site will show 🧸 and 🐼 emoji instead — still cute!

### 4. Open the Website
- Double-click `index.html` to open in your browser, **OR**
- Right-click → Open with → Chrome/Edge/Firefox
